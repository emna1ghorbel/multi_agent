# Agent-CTI Project

Multi-Agent Cyber Threat Intelligence system.

## Architecture
- `core/`: Config and LLM helpers
- `tools/`: Extraction, Search, Pattern and Behavior detection
- `agents/`: AI agents for analysis and MITRE mapping
- `mitre/`: MITRE ATT&CK engines
- `reporting/`: Dashboard and PDF reports
- `api/`: FastAPI layer
- `pipeline/`: LangGraph orchestration
